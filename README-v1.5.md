# Angkea Sil Learning — Theme v1.5 Cart

Changes:
- Removed PDF / E-book / Worksheet pills from the Books “ឆាប់ៗនេះ” popup.
- Added a working shopping cart popup.
- Paid course cards now include “＋ កន្ត្រក” and “ទិញឥឡូវ”.
- Cart shows each selected lesson, each price, item count, and total price.
- Items can be removed from the cart.
- Users can start payment from the cart or pay a specific course.
- When PayWay returns APPROVED, the paid course is removed from the cart and remains in “មេរៀនទិញ”.

Important:
The current ABA PayWay backend creates one KHQR transaction per course, so multiple cart items are paid one course at a time. The cart still shows the combined total for review.

Never upload `.env`, API keys, passwords, PINs, or secret credentials to GitHub.
